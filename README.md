# GreenPlum

В шестом практическом домашнем задании наша задача загрузить файл в GreenPlum

Результаты работы:
+ Создана таблица в GreenPlum в базе данных idp, соответствующая нашему имени пользователя user*
+ В таблице лежат данные из файла
+ К таблице можно применить запрос SELECT и он успешно выдает данные

В рамках учебного курса нам предоставили сервер для выполнения домашнего задания.

Мы разбили задачу на отдельные шаги, которые вы найдете в markdown-файле **greenplum.md**.
